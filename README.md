## How to use this directory

Each row links to a primary source operated by the provider or an official public institution. The directory records the benefit, eligibility, deadline status for **2026** and **2027**, and the last date the source was checked.

Amounts are shown in the source currency. “Rolling” means the official source describes ongoing applications or no cohort deadline. “Not published” does not mean that a program is closed.

## Status labels

- **Active / rolling:** the official source currently presents the program and accepts applications or describes ongoing access.
- **Active / deadline not published:** the program is presented as current, but no 2026 or 2027 deadline is published.
- **Open call coming soon:** the official source describes a future call but does not publish an application deadline.
- **Unconfirmed:** an official program page was not found or the available official information is insufficient; do not treat the entry as an open offer.
- **Expired:** the official source shows that the relevant call has ended.

## Scope and maintenance

This is a curated starting set, not a promise that every program is available in every country. Contributions should preserve primary-source links, avoid inferred deadlines, and update the **Last verified** date whenever a row changes.
