# Regional Startup Credits & Funding Research — 2026-10-24

تم جمع 76 سجلًا عبر 8 نطاقات بحثية: الهند، أوكرانيا، إسرائيل، البرازيل، البرتغال، إسبانيا، دول الاتحاد الأوروبي، وآسيا. تشمل النتائج Cloud/API/AI credits، منحًا وتمويلًا حكوميًا، برامج SaaS، مسرّعات، وضمانات ائتمانية.

## نتيجة الأكواد

لم يتم العثور على **Promo Code أو Referral Code عام منشور** في الصفحات الرسمية التي تم التحقق منها. هذا لا يعني عدم وجود أكواد خاصة بالشركاء أو المستثمرين؛ بعض البرامج تستخدم إحالة خاصة أو ترسل كودًا فريدًا بعد القبول، مثل برامج Microsoft وMongoDB وAWS Activate Portfolio. لذلك تم تسجيل هذه الحالات كـ `No public code verified` بدل اختراع كود أو اعتبار رابط التقديم كودًا.

## ملاحظات عملية

- الهند: من أبرز المسارات Startup India Seed Fund Scheme، وCredit Guarantee Scheme for Startups، وبرامج Google Cloud/AWS/Microsoft العالمية، إضافة إلى HubSpot Bootstrap للهند.
- أوكرانيا: Ukraine Support Fund مغلق كصندوق نهائي، بينما مسار Microsoft المرتبط بـ Ukrainian Startup Fund وبرنامج Startup EDGE يستحق المتابعة؛ بعض المنح السابقة منتهية أو تاريخية.
- إسرائيل: توجد مسارات محلية قوية من Israel Innovation Authority، إلى جانب Google Cloud Israel Hub وAkamai Rise وCloudflare وDigitalOcean.
- البرازيل: توجد برامج Google Accelerator وSebrae وBNDES، مع برامج عالمية للـ cloud والـ SaaS متاحة وفق شروط الأهلية.
- البرتغال: من أبرز المسارات Vouchers for Startups وStartUP Voucher وEmpreende XXI وSIFIDE؛ بعض الدعوات مغلقة ويجب فحص المواعيد الحالية.
- إسبانيا: تشمل النتائج ENISA، NEOTEC، Acelera Pyme، OVHcloud وWayra/DigitalOcean، مع فصل الدعوات المنتهية عن الخدمات المفتوحة.
- الاتحاد الأوروبي: تشمل EIC Accelerator، EIT Urban Mobility، Women TechEU، Stripe Startups، Notion for Startups، وبرامج SaaS/AI عالمية.
- آسيا: تشمل Google Cloud، AWS Activate، Microsoft for Startups، Google Accelerator Southeast Asia، وبرامج APJ، مع تحديد الدورات المغلقة بوضوح.

## طريقة الاستخدام

استخدم ورقة `Regional Programs` للتصفية حسب المنطقة والدولة ونوع المنفعة والحالة. استخدم ورقة `Promo & Referral Codes` لتتبع حالة الأكواد؛ جميع السجلات الحالية تحمل حالة عدم التحقق من كود عام. استخدم ورقة `Regional Summary` للمقارنة السريعة بين المناطق.

القيم القصوى هي ceilings إعلانية وليست ضمانًا، ولا يجوز جمعها بين البرامج أو اعتبارها نقدًا إلا إذا كان نوع المنفعة Grant/Cash واضحًا.

البيانات التفصيلية، روابط التقديم، وروابط الأدلة الرسمية موجودة في ملف CSV وورقة Excel. تم حفظ نسخة JSON الخام من نتائج البحث في `research/regional-startup-credits-raw-2026-10-24.json` لأغراض التتبع وإعادة البناء.
