# Resourify Credits Discovery Index

Source directory: [Resourify — Credits](https://resourify.com/category/credits)

**Research date:** 2026-10-14

This is a discovery index of credit-related pages listed by Resourify. It is deliberately separate from the verified active program dataset. A Resourify listing is not treated as a primary source; a program is promoted into `programs.csv` only after the provider's official page confirms the benefit and eligibility.

Resourify discloses that it may earn affiliate commissions. Treat affiliate links as commercial tracking links and prefer the official provider link shown on each verified entry in this repository.

## Code and source rules

- A code shown by Resourify is recorded as a **lead**, not as a verified code.
- A code enters the active directory only when the vendor's official page or official checkout instructions publish it or confirm its current validity.
- Affiliate URLs are not substituted for official application URLs.
- Expired or inactive Resourify listings remain here only for auditability and are not counted as active programs.
