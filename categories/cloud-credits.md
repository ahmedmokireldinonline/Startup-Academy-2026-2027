## Coupon interpretation

- **Official code available:** the provider publishes the code on its own page or official instructions.
- **No public code verified:** use the official application or signup route; do not copy codes from third-party posts without provider confirmation.
- **Unverified third-party code:** record it in `imports/resourify/README.md` or an issue, but do not present it as active.
