# Credits والمنح والدعم المالي الموثق — إضافات جديدة

آخر مراجعة: **2026-10-14**

يضم هذا الملف برامج إضافية تم التحقق منها من مصادر رسمية أولية، مع التركيز على المنافع المالية المحددة. قد تكون المنفعة رصيدًا سحابيًا، أو منحة، أو حافزًا ضريبيًا، أو ضمانًا ائتمانيًا، أو دعمًا للابتكار؛ وهذه الأنواع ليست متطابقة، لذلك تم توضيح النوع لكل برنامج.

**سياسة الأكواد:** لا يتم إدراج أي كوبون أو referral code غير رسمي. حتى تاريخ المراجعة، لم أجد كودًا عامًا رسميًا يمكن تأكيد صلاحيته حاليًا للبرامج أدناه. قد تطلب بعض البرامج شريكًا أو مُقرضًا أو referral أو معرّفًا داخل بوابة التقديم.

## التمييز المهم

تقلل Cloud credits فاتورة البنية التحتية. أما المنح والإعانات فتمول أو تعوض تكاليف مؤهلة. وتُطالب الحوافز الضريبية عبر الإقرار الضريبي وبعد تحقق المصروفات والشروط. أما الضمان الائتماني فيدعم قرار المُقرض ولا يساوي منحة نقدية مباشرة.
