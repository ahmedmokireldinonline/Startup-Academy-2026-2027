# SaaS Startup Financial Model Package (English)

## What this package is

This is an original, English-language SaaS startup financial model package built from the publicly described feature set of the reference product page. It is not a copy of the paid workbook, does not reproduce its proprietary formulas or layout, and does not include an unauthorized download of the product.

The reference page describes a paid Excel template priced at **$90** with a five-year monthly forecast, an 18-month pre-seed plan, assumptions, customer revenue build, headcount, operating expenses, COGS and gross margin, P&L, cash flow, balance sheet, fundraising cap table, KPI metrics, dashboard and model checks. The package below covers those functional modules and adds explicit auditability, scenario control, data validation, standalone extracts, and integrity tests.

## Files

1. **00_SaaS_Startup_Financial_Model_MASTER.xlsx** — the integrated workbook. Use this for live scenario modeling. It contains 13 tabs: Dashboard, Assumptions, Pre-Seed, Revenue Build, Headcount, Opex, COGS, P&L, Cash Flow, Balance Sheet, Cap Table, KPIs and Checks.
2. **01_Assumptions.xlsx** — all model inputs in one place: start date, scenario, funnel, pricing, churn, cost drivers, hiring plan, funding plan and scenario multipliers.
3. **02_Pre-Seed_Projections.xlsx** — an 18-month plan for leads, trials, customers, MRR, burn, cash, runway and milestone progress.
4. **03_Customer_Revenue_Build.xlsx** — the customer funnel and recurring-revenue engine: leads, demos, trials, paid customers, churn, expansion, MRR, ARR, billings and unit economics.
5. **04_Headcount_Plan.xlsx** — role-based hiring plan, total headcount and payroll burden.
6. **05_Operating_Expenses.xlsx** — payroll, commissions, marketing, software, legal, office, stock-based compensation and D&A.
7. **06_COGS_Gross_Margin.xlsx** — hosting, payment processing, customer success delivery, implementation delivery, gross profit and gross margin.
8. **07_Profit_and_Loss.xlsx** — monthly income statement from revenue through net income.
9. **08_Cash_Flow.xlsx** — indirect cash flow, financing receipts, burn, runway and ending cash.
10. **09_Balance_Sheet.xlsx** — cash, receivables, prepaids, PP&E, payables, deferred revenue, debt and equity with a balance check.
11. **10_Fundraising_Cap_Table.xlsx** — founder capital, SAFE, seed and venture debt rows with ownership placeholders and option pool logic.
12. **11_KPI_Metrics.xlsx** — MRR, ARR, growth, customer growth, gross margin, CAC, LTV, LTV/CAC, payback, burn multiple, runway, Rule of 40 and ARR/employee.
13. **12_Cover_Dashboard.xlsx** — headline KPIs, five-year annual summary and revenue trend chart.
14. **13_Model_Checks.xlsx** — balance sheet, cash roll-forward, revenue and customer sanity checks.

## Improvements added beyond the public description

The model includes a centralized scenario selector, comments on hardcoded inputs, blue/green/black finance-model color coding, a standalone-file guide in every extract, data validation for the scenario selector, explicit integrity checks, zero-division guards, and an independent audit trail. It also preserves an illustrative base case so the workbooks open with visible outputs instead of blank templates.

## How to use

Open the master workbook and start in **Assumptions**. Change the model start date, scenario, funnel, pricing, churn, hiring and funding inputs. Review **Dashboard**, **KPIs**, **Cash Flow** and **Checks**. The separate files are useful when sharing only one module with an investor, board member or operating owner.

The numbers are illustrative assumptions, not company-specific forecasts. Replace them with actual company data and document the source in each blue input cell's comment. The model is for planning and analysis and is not investment, tax, legal or accounting advice.
